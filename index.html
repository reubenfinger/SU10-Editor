Yamaha SU10 Editor

Web MIDI editor and librarian for the SU10: open and edit bulk dumps, build new memories from folders of samples, chop, loop, tune and send back to the unit.

Open the editor Download (one HTML file)
Works in Chrome, Edge or Opera on desktop. Click Connect MIDI and allow System Exclusive access. The downloaded file runs offline: just open it in the browser. Source, README and licence on GitHub · MIT
